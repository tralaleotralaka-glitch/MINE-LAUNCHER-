# Mine Launcher — Minecraft-style launcher + воксельная игра для Android

Полноценный мобильный лаунчер в стиле Minecraft **Java Edition** с настоящей игрой внутри:
кнопка **ИГРАТЬ** → главное меню Minecraft → создание мира → выбор режима игры →
и вы попадаете в интерактивный воксельный мир на OpenGL ES 2.0.

> ⚠️ **Важно:** это самостоятельная игра-«песочница» в стиле Minecraft, написанная с нуля
> (движок, генератор мира, текстуры, физика). Это **не** официальный клиент Minecraft Java
> Edition и он не использует файлы, ассеты или код Mojang. Чтобы играть именно в
> оригинальный Java Edition на Android, нужен PojavLauncher и лицензия Minecraft —
> такой клиент нельзя пересобрать из исходников без самих файлов игры.

## Что внутри

**Экраны**
1. **Лаунчер** — никнейм, выбор версии (1.7.10 … 1.21.4), прогресс запуска, большая кнопка `ИГРАТЬ`.
2. **Главное меню** — «Minecraft»-стиль: Одиночная игра / Настройки / Выход.
3. **Создание мира** — название, сид, режим игры: Выживание / Творческий / Приключение / Хардкор.
4. **Игра** — полноэкранный 3D-мир с джойстиком, обзором свайпом, разрушением и установкой блоков.

**Движок (`app/src/main/java/com/minelauncher/app/game`)**
* `World` — мир 192×192×72 блока (`byte[]`), генерация ландшафта по value-noise (fBm),
  горы, океаны, пляжи, деревья; DDA-рейкаст для наведения на блок.
* `WorldRenderer` — OpenGL ES 2.0: чанки 16×16, VBO на чанк, отсечение невидимых граней,
  затенение по нормалям, туман, атлас текстур 4×4, **нарисованный процедурно** (никаких
  PNG-ассетов, всё в коде).
* `Player` — AABB-коллизии, гравитация, прыжок, плавание, полёт в творческом режиме.
* `GameSurfaceView` — рендер-цикл, многоточечный тач (джойстик + обзор), прогрессивная
  сборка мешей, перестройка чанков после изменения блока.

**Режимы игры**: в творческом доступен полёт (кнопка ✈), во всех режимах — ломание (⛏)
и установка (▣) блоков, хотбар из 9 блоков внизу экрана.

## Управление в игре

| | |
|---|---|
| Левая половина экрана | виртуальный джойстик движения |
| Правая половина экрана | обзор (свайп) |
| ▲ / ▼ | прыжок / присесть (в полёте — вверх / вниз) |
| ⛏ | сломать блок в прицеле |
| ▣ | поставить выбранный блок |
| ✈ | включить/выключить полёт (только творческий) |
| ❚❚ или «Назад» | пауза |

## Сборка APK

APK собирается автоматически в GitHub Actions: workflow `.github/workflows/build-apk.yml`
запускается на каждый push и на `workflow_dispatch`.

* Готовый файл: раздел **Releases** → `v1.0` → `MineLauncher-1.0.apk`,
  а также артефакт `MineLauncher-apk` в разделе **Actions**.
* Локальная сборка: `gradle assembleDebug` (нужны JDK 17 и Android SDK, `ANDROID_HOME`).
  APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

**Установка:** скачайте APK на телефон, откройте файл и разрешите установку из
неизвестных источников. Нужен Android 5.0+ и поддержка OpenGL ES 2.0.

## Технические параметры

* `applicationId`: `com.minelauncher.app`, `minSdk 21`, `targetSdk 34`, Java 17, без внешних зависимостей.
* Ориентация: лаунчер и меню — портрет, игра — ландшафт.
